# PorongComercio es un proyecto de tienda digital.

El primer objetivo es coger la plantilla MultiShop y dividir index.html en secciones individuales en archivos .php y cargarlas secuencialmente para formar la página. A partir de ahí sería ir modificando cada .php para formar la página deseada.

Para el desarrollo, no haremos commits a la rama "main", sino que haremos como en ISO2 y todo del desarrollo se hará en ramas aparte hasta que sea estable, una vez tengamos una versión estable la mergearemos a "main".
